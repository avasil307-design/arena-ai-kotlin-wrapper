# Arena — Android WebView

Минимальная неофициальная обёртка https://arena.ai на Kotlin. Не связана с владельцами сайта. Собственная геометрическая иконка «A», без использования логотипов Arena.

## Скачать APK без Java и Android Studio

Сборка выполняется на GitHub Actions, локально ничего устанавливать не нужно.

1. Откройте [Actions → Build debug APK](https://github.com/avasil307-design/arena-ai-kotlin-wrapper/actions/workflows/android-debug.yml).
2. Выберите последний запуск для вашей ветки и дождитесь зелёной галочки. При ошибке откройте шаг сборки и его журнал.
3. Внизу страницы запуска, в **Artifacts**, скачайте **Arena-debug-APK** (нужно войти в GitHub).
4. Распакуйте ZIP: внутри находится `app-debug.apk`. Передайте его на Android и установите, разрешив установку из этого источника, если система попросит.

Сборка стартует автоматически при push в рабочую ветку или `main`, а также для pull request. После появления workflow в основной ветке доступен ручной запуск **Run workflow**. Артефакты хранятся 14 дней. Это отладочная сборка, не релиз для Google Play. Ключ отладки на разных запусках CI может отличаться: если Android не позволяет обновить старую установку, удалите её перед установкой нового APK (сессия и данные приложения будут потеряны).

## Открыть в Android Studio

1. Установите актуальную Android Studio (Ladybug или новее).
2. Выберите **Open** и откройте корневую папку этого проекта (не папку `app`).
3. В SDK Manager установите **Android SDK Platform 35**, Android SDK Build-Tools и Platform-Tools. Минимальная версия устройства — Android 8.0 (API 26).
4. Используйте **JDK 17** для Gradle: Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK. Дождитесь Gradle Sync.

Android Studio создаст `local.properties` с путём к SDK. Для командной строки можно вместо этого задать `ANDROID_HOME`. Файл `local.properties` не следует добавлять в Git.

Версии: Gradle 8.9 (wrapper включён), Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compile/target SDK 35. Для первой сборки нужен доступ к серверам Gradle, Google Maven и Maven Central.

## Debug APK

Linux/macOS:

```sh
./gradlew assembleDebug
```

Windows:

```bat
gradlew.bat assembleDebug
```

Результат: **`app/build/outputs/apk/debug/app-debug.apk`**. APK подписан стандартным отладочным ключом, release-ключ не нужен. Можно также использовать Build → Build App Bundle(s) / APK(s) → Build APK(s) в Android Studio.

Установка на подключённое устройство с включённой USB-отладкой:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Проверки Android Lint: `./gradlew lintDebug`.

## Поведение

- Весь доступный экран занимает сайт: собственной панели, адресной строки и кнопок нет. Системные панели остаются видимыми и тёмными; учтены inset-отступы Android 15 и клавиатуры. Загрузка и ошибки отображаются на чёрном фоне.
- Приложение использует тёмную системную тему и разрешает алгоритмическое затемнение на Android 13+. Окончательное оформление страниц определяется также сайтом и версией Android System WebView.
- «Назад» возвращает по истории WebView, а без истории закрывает Activity. История восстанавливается при пересоздании Activity.
- HTTPS-ссылки строго на `arena.ai` остаются внутри. HTTP-ссылки этого хоста повышаются до HTTPS. Другие хосты (включая поддомены) открываются снаружи; `mailto:` и `tel:` передаются системным обработчикам. Popup-ссылки с пользовательским жестом проходят ту же проверку. Неизвестные и опасные схемы блокируются.
- JavaScript и DOM storage включены. Постоянные cookies сохраняются WebView, CookieManager выполняет flush при завершении страницы и уходе в фон. Данные не очищаются при перезапуске. Срок сессии определяет сервер: приложение не превращает временные cookies в постоянные и не гарантирует бессрочный вход. Очистка данных приложения/удаление приложения сбрасывает вход.
- Файлы выбираются системным picker с MIME-фильтрами и режимом множественного выбора, запрошенными сайтом. Разрешения на хранилище, камеру и микрофон не запрашиваются. Съёмка камерой, запись звука и скачивание файлов не реализованы.
- При ошибке основного документа (сеть, HTTP 4xx/5xx) показывается экран с кнопкой «Повторить». Ошибки вспомогательных ресурсов не перекрывают страницу. Ошибки сертификатов не обходятся. Если сайт сам показывает ошибку внутри SPA при успешном HTTP-ответе, это остаётся интерфейсом сайта.

## Google и безопасность авторизации

Google и другие провайдеры могут запрещать OAuth во встроенном WebView (`disallowed_useragent`). При переходе на `accounts.google.com` приложение объясняет ограничение и предлагает открыть **https://arena.ai/** в обычном браузере. Продолжайте вход и работу в этом браузере; при желании добавьте сайт на главный экран средствами браузера. Если сайт предоставляет другой разрешённый способ входа, используйте его в приложении.

**Браузер и WebView не делят хранилище cookies.** Вход в браузере не авторизует WebView автоматически. Приложение не подменяет User-Agent, не перехватывает пароли или OAuth-токены, не копирует cookies из браузера и не обходит ограничения. Если сайт изменит адреса авторизации или покажет встроенную ошибку, используйте браузер напрямую.

Единственное разрешение — `INTERNET`. Нет рекламы, аналитики, сторонних SDK, JavaScript bridge или разрешений на доступ ко всему хранилищу. Сторонние cookies отключены; это может ограничивать некоторые встроенные способы авторизации. HTTP/mixed content и доступ WebView к локальным файлам отключены, резервное копирование данных приложения отключено. Сам сайт имеет собственную политику обработки данных.

## Ручная проверка на устройстве

1. Запустить при доступной сети: нет панели приложения, обе системные панели тёмные; проверить портрет, альбомную ориентацию, клавиатуру и жестовую/трёхкнопочную навигацию.
2. Перейти по внутренней ссылке → «Назад» возвращает; без истории → приложение закрывается.
3. Открыть внешнюю ссылку и ссылку с `target=_blank`: внешний сайт открывается в браузере. Проверить, что `arena.ai.evil.example` не считается внутренним.
4. Авторизоваться доступным способом, закрыть и повторно открыть приложение: проверить действующую серверную сессию. Проверить поворот экрана.
5. Нажать загрузку вложения: выбрать один/несколько файлов, отменить выбор, повторить. Проверить отмену при повороте экрана.
6. Отключить сеть, перезапустить приложение: экран ошибки. Вернуть сеть → «Повторить». Проверить также недоступность сервера.
7. Попробовать Google-вход: объяснение и переход на Arena в браузере без обещания переноса сессии.

## Проверки в среде создания

Структура проекта, XML-ресурсы и наличие Gradle wrapper проверены статически. Сборка APK, Android Lint и запуск на эмуляторе здесь не выполнялись: в среде нет JDK и Android SDK. Перед распространением выполните команды выше и ручные проверки на реальном устройстве с актуальным Android System WebView.
